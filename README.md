Custom TradingView Indicator
Профессиональный кастомный индикатор для платформы TradingView, написанный на Pine Script v5.

Closed Source. Исходный код в этом репозитории не публикуется — индикатор частный. Репозиторий служит витриной проекта.

О проекте
Полноценный мультитаймфрейм-индикатор, написанный и оптимизированный под реальную торговлю. Работает стабильно, без перерисовки (non-repainting), нагрузка на график минимальная.
Ключевые особенности

Pine Script v5 — актуальная версия языка TradingView
Мультитаймфрейм-анализ — данные с нескольких таймфреймов в одном окне
Оптимизированный код — без тормозов даже на долгой истории
Настраиваемые параметры — подстраивается под стиль трейдера
Alerts — уведомления через TradingView на email, Telegram, webhook
Работает на любых рынках — крипта, форекс, акции, фьючерсы
